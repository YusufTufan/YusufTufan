### <p align="center">🔭 What I'm Working On</p>
<p align="center">
  🛡️ <strong>AI-Assisted Security Auditing Plugin for IDEs</strong> (Undergraduate Thesis, ongoing)<br>
  An IDE plugin that combines AST-based static analysis (SAST) with a retrieval-augmented LLM (RAG)<br>
  to detect insecure code and suggest fixes while the developer is writing it.<br>
  The design is informed by a study of where AI coding agents fail across the SDLC:<br>
  context loss, hallucination, and insecure code.
</p>
